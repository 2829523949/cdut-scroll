# 成理刷屏人格测试

网站：https://2829523949.github.io/cdut-scroll/

16 道题，包括单选、多选和 1—5 分评分。第 9 题最多选择三项；第 4 题选择“基本不看”后跳过剩余问题，展示轻接触结果。

保留题目和选项顺序；第 6 题原选项编号由 D 跳至 F，沿用原编号。性别、年级、专业、平台来源和认同评分不参与人格计分。多选题按题内平均计入。

四维切片和主持风格建议为本站制作的娱乐解读，并非原问卷提供的标准量表；不构成心理测量。评分题保留原始感受，单独展示。

网页文件位于仓库根目录，无需构建。GitHub Pages 从 main 分支根目录发布，更新文件后会自动部署。

## 答卷管理

管理入口：https://2829523949.github.io/cdut-scroll/admin.html

答卷管理需要管理密码登录，支持查看每份原始答案和四维结果、按日期与人格筛选、查看汇总统计，以及导出可用 Excel 打开的 CSV。数据由 Cloudflare 的私有 D1 数据库保存，不写入本公共仓库。

参与者先同意答卷保存说明后才会提交，旧进度不会追溯上传。保存失败会显示重试提示，画像仍可查看。修改同一份答卷会更新原记录，不重复计数。部署说明见 [backend/README.md](backend/README.md)。
